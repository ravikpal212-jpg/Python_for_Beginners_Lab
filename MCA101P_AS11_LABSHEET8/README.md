# Python Lab Sheet 08 — Database Management

Each question is provided as a separate Python source file (`Q01.py`, `Q02.py`, ...).

## Run
```bash
python Q01.py
```
Run the desired question file from a terminal or Python IDE. Some programs ask for input. Database labs use Python's built-in `sqlite3` module so they can run without installing MySQL connectors.

Uses SQLite (`sqlite3`) instead of MySQL so the examples run with standard Python. The shared `db_common.py` initializes student_db.sqlite and the common tables.
